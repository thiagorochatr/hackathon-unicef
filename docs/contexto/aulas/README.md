## ⚠️ Consumo logado é critério de desempate

O progresso é registrado **por navegador + e-mail de acesso** ("O progresso foi salvo neste navegador"). Este material extraído serve como contexto de estudo e para o projeto — **não substitui o consumo na plataforma**. Cada membro da equipe (Thiago e Lais) deve acessar com o próprio e-mail no próprio navegador, abrir todas as aulas e responder os quizzes. Segundo a live de abertura, esse desempate "é muito usado" e pode decidir pódio.
